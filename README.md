# Лабораторные работы по Kotlin

Репозиторий содержит две консольные программы для Kotlin/JVM. Каждая лабораторная запускается отдельно через свой `src/Main.kt` в IntelliJ IDEA.

## Лабораторная работа №1 — тарификация звонка

Файл: `Lab1/src/Main.kt`. Программа рассчитывает стоимость звонка для одного абонента. Каждая начатая минута оплачивается полностью. Тарифы: `START` — 3 ₽/мин, `STANDARD` — 2 ₽/мин, `PREMIUM` — 1 ₽/мин. Поддерживается скидка от 0 до 100%. При недостаточном балансе списания нет; неизвестный тариф и некорректные значения отклоняются.

Без аргументов выполняется контрольный сценарий: тариф `STANDARD`, баланс 100 ₽, звонок 125 секунд. Результат — 3 тарифицируемые минуты, стоимость 6 ₽, остаток 94 ₽.

Аргументы командной строки: `<тариф> <баланс> <секунды> [скидка_%]`. Пример: `STANDARD 100 125 20`.

## Лабораторная работа №2 — абоненты и тарифы

Файл: `Lab2/src/Main.kt`. Модель в пакете `lab02` включает `Subscriber`, `Account` и `Tariff`. Тарифы и состояния счёта представлены перечислениями. Email может отсутствовать; при выводе используется «не указан». Списание отклоняется при недостаточном балансе или состоянии `BLOCKED`.

Программа тарифицирует звонки длительностью 125 секунд для Ивана Петрова и Анны Смирновой. Стоимость составляет 6 ₽ и 3 ₽, остатки на счетах — 94 ₽ и 247 ₽ соответственно.
