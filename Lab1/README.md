# Лабораторная работа №1 — тарификация голосового вызова

Консольная программа рассчитывает стоимость звонка для одного абонента. Каждая начатая минута оплачивается полностью. Поддерживаются тарифы `START` (3 ₽/мин), `STANDARD` (2 ₽/мин), `PREMIUM` (1 ₽/мин) и скидка от 0 до 100%. При недостаточном балансе списания нет; неизвестный тариф и некорректные значения отклоняются.

## Запуск

Откройте `Lab1` как проект Kotlin/JVM в IntelliJ IDEA и запустите `src/Main.kt`. Без аргументов выполняется контрольный сценарий: `STANDARD`, 100 ₽, 125 секунд; результат — 3 минуты, 6 ₽ и баланс 94 ₽.

Необязательные аргументы командной строки: `<тариф> <баланс> <секунды> [скидка_%]`. Например: `STANDARD 100 125 20`.
